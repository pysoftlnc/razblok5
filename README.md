## О проекте

**Razblok5** — это форк youtube-discord с расширенным списком доменов для обхода блокировок. 
Список содержит более 300 доменов популярных сервисов.

## Состав репозитория

| Файл | Назначение |
|------|------------|
| `list-general.txt` | Список доменов (Discord, Telegram, YouTube, WhatsApp, Roblox, Cloudflare) |
| `general.bat` | Готовый файл для запуска GoodbyeDPI |

## Быстрый старт

### Шаг 1. Скачайте архив
Нажмите зеленую кнопку **"Code"** → **"Download ZIP"**

### Шаг 2. Распакуйте архив
Извлеките все файлы в отдельную папку, например `C:\razblok5`

### Шаг 3. Запустите файл **`general.bat`**
Просто дважды кликните по файлу. Программа сама запросит права администратора.

## Другие варианты запуска

В архиве есть дополнительные файлы на разные случаи:

| Файл | Описание |
|------|----------|
| `general (FAKE TLS AUTO).bat` | Автоматический режим с подменой TLS |
| `general (SIMPLE FAKE).bat` | Упрощенный режим с подменой трафика (fake) для обхода глубокой проверки пакетов |
| `general (ALT 1-11).bat` | Если не работает обычный general |

> [!TIP]
> ** Полезные советы если что-то пошло не так**
>
> ### 1. Проверьте антивирус
> Некоторые антивирусы могут блокировать GoodbyeDPI. Добавьте папку с программой в исключения.
>
> ### 2. PowerShell в PATH
> Если видите ошибку про PowerShell:
> 1. Откройте **Параметры системы** → **Дополнительные параметры системы**
> 2. Нажмите **Переменные среды**
> 3. Найдите **Path** → **Изменить**
> 4. Добавьте: `C:\Windows\System32\WindowsPowerShell\v1.0\`
> 5. Нажмите **ОК** и перезапустите компьютер
>
> ### 3. Попробуйте другой файл
> Если `general.bat` не работает, используйте один из дополнительных файлов (ALT, FAKE TLS AUTO и т.д.)

## Смена DNS (если нужно)

Откройте любой `.bat` файл в блокноте и найдите строку с `--dns-addr`. Замените на один из вариантов:

```batch
:: Яндекс DNS (по умолчанию, работает в РФ)
--dns-addr 77.88.8.8 --dns-port 1253

:: Google DNS
--dns-addr 8.8.8.8 --dns-port 53

:: Cloudflare DNS
--dns-addr 1.1.1.1 --dns-port 53
```
